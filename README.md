# PumpLab Coming Soon

Static multilingual single page for GitHub Pages.

The page uses one combined brand asset:

```text
assets/brand/pumplab-logo.svg
```

No separate waveform is placed above the wordmark.

## Languages

EN, ME, RU.

Edit translations:

```text
src/scripts/data/translations.js
```
